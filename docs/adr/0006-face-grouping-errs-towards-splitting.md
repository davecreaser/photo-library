# Face grouping errs towards splitting people, not merging them

Grouping and matching thresholds are deliberately conservative. One person spread over two face groups is fixed with no extra work (give both the same name and they merge). Two people mixed into one group means reviewing faces one by one. Expect more, smaller face groups than a tool tuned for recall would show; don't "improve" this by loosening thresholds without real-library measurements.
